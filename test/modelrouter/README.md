# test/modelrouter/

Tests, load drivers, and result artifacts for the quality-aware router
(`src/coordinator/router/`).

## Scripts

| script | purpose |
|---|---|
| `verify_router.py` | quick sanity check — probes a running coordinator with trivial and hard prompts, verifies hard prompts land on workers advertising `model_quality >= 0.8` |
| `build_prompts.py` | generate a deterministic mixed-complexity prompt workload (seeded) |
| `replay.py` | closed-loop load generator — fires N concurrent sessions of M requests, records TTFT / decode rate / chosen worker per request |
| `run_ablation.sh` | restarts the coordinator with different scheduler weights and runs `replay.py` for each configuration |
| `quality_eval.py` | A/B answer-quality comparison between a strong and a weak model worker, with optional LLM-as-judge |
| `analyze.py` | turns `results/ablation.csv` into markdown tables + matplotlib plots |

## Typical flows

**Sanity check while iterating on the router:**

```bash
python test/modelrouter/verify_router.py --coordinator http://127.0.0.1:8080
```

**Full ablation (requires three workers and a coordinator running):**

```bash
python test/modelrouter/build_prompts.py --n 30 --seed 42 \
    --out test/modelrouter/data/prompts.jsonl
./test/modelrouter/run_ablation.sh
python test/modelrouter/analyze.py
```

**Direct strong-vs-weak answer-quality comparison:**

```bash
python test/modelrouter/quality_eval.py
```

## Result artifacts

`results/` contains the canned outputs from the last full ablation
(TinyLlama-only Phase A and Gemma/TinyLlama Phase B), plus the canned
quality-eval output. They are checked in so SCHEDULER.md can reference
them without requiring readers to re-run the harness.

| file | what it is |
|---|---|
| `ablation.csv` | per-request rows for every ablation configuration |
| `summary.md` | tabulated summary (regenerated by `analyze.py`) |
| `ttft_p50_p90_p99.png` | TTFT percentiles per configuration |
| `worker_distribution.png` | request count per worker per configuration |
| `rejection_rate.png` | shed rate under tight SLO |
| `quality_eval.md` + `quality_eval.json` | per-prompt strong vs weak answers + judge verdicts |
